# EasyBI

Projeto acadêmico simples de **Business Intelligence** com dados de interessados e matrículas da escola profissionalizante Easycomp, recebidos pelo Instagram.

O programa usa **Pandas** para resumir os dados e calcular a conversão por curso, e **Matplotlib** para apresentar os resultados em três gráficos.

## Executar

```bash
py -m pip install -r requirements.txt
py main.py
```

Os arquivos `dados.csv` e `main.py` devem permanecer na mesma pasta.
